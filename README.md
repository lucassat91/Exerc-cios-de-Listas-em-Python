# Exercícios de listas em Python

Seis scripts de prática com **listas**, cada um resolve um problema e mostra o resultado no terminal.

| Script | Exercício | Conceitos |
|---|---|---|
| `1.py` | Maior, menor e soma de uma lista de 5 números | `max`, `min`, `sum` |
| `2.py` | Ler 3 nomes do usuário e guardar em uma lista | `input`, `for`, `append` |
| `3.py` | Lista de 1 a 10 mostrando só os pares | `range`, *list comprehension* |
| `4.py` | Média de cada aluno e classificação em aprovados, recuperação e reprovados | listas aninhadas, `if/elif/else`, `round` |
| `5.py` | Remover duplicados mantendo a ordem original | funções, lista auxiliar de itens vistos (sem `set`) |
| `6.py` | Maior sequência crescente contínua, com desafio extra que devolve também índice inicial, final e tamanho | funções, fatiamento, cópia de lista |

## Como executar

```bash
python3 1.py
```

Troque `1.py` pelo script que quiser. Não há dependências externas. Basta ter o Python 3 instalado.

## O que pratiquei

- Percorrer, filtrar e transformar listas
- Escrever funções com casos de teste simples
- Resolver problemas sem atalhos prontos (por exemplo, remover duplicados sem `set`) para treinar a lógica
